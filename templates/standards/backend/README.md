# Esqueleto backend monolito modular

Este paquete muestra límites iniciales sin fijar el stack pendiente de ADR-0003. Copia `src/` y `.dependency-cruiser.cjs` al proyecto destino. Añade las dependencias exactas acordadas allí; consulta `docs/standards/backend.md` para las reglas y `.agents/skills/backend-architecture/` para las instrucciones del agente.

Las carpetas `.gitkeep` solo representan ubicaciones iniciales; elimina las que no tengan contenido real.
