# Requisitos

Crea un documento por cada comportamiento de producto que pueda probarse de forma independiente, utilizando identificadores REQ estables y la plantilla docs/templates/requirement.md.

Los requisitos describen comportamiento observable y criterios de aceptación; no deben imponer detalles de implementación salvo que exista una restricción técnica necesaria.

| ID | Requisito | Estado |
|---|---|---|
| REQ-001 | [Espacio de trabajo local de proyectos](REQ-001-local-project-workspace.md) | Borrador |

Utiliza pnpm run new:requirement -- <slug> para crear el siguiente borrador numerado.
