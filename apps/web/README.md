# Aplicación web

SPA React + Vite + TypeScript servida por el backend local.

La interfaz ofrece exploración de archivos, documentación, requisitos, estado declarado del proyecto y Git de solo lectura. Usa TanStack Query para datos de API y DOMPurify para Markdown; Mermaid se renderiza en modo estricto y se bloquean imágenes remotas.

Consulta la [arquitectura del frontend](../../docs/architecture/frontend.md). El navegador no accede directamente al sistema de archivos ni a procesos.
