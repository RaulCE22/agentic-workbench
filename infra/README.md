# Infraestructura

Agentic Workbench es una aplicación local-first. No necesita despliegue en Hetzner, Docker, Dockge, Traefik ni Cloudflare para funcionar.

La carpeta `infra/` se conserva por herencia y no contiene infraestructura activa del producto. Workbench se ejecuta localmente sin Docker ni servicios cloud.

Consulta el modelo vigente en [arquitectura de infraestructura](../docs/architecture/infrastructure.md). No añadas despliegue remoto sin una decisión aprobada.
