# Paquete de contratos

Directorio reservado para contratos de transporte Zod compartidos por apps/web y apps/api.

Contenidos posibles:
- Esquemas de petición y respuesta.
- Esquemas comunes de paginación y formato de error.
- Enumeraciones y tipos públicos.

No incluyas definiciones de tablas Drizzle, entidades de base de datos, servicios de aplicación, secretos ni modelos de vista frontend. Crea el package.json y sus exportaciones cuando aparezca el primer contrato realmente compartido.
